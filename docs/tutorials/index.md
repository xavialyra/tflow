# Tutorials

Tutorials are learning-oriented guides designed to take you by the hand through a step-by-step onboarding experience.

## Available Tutorials

1. **[Getting Started](getting-started.md)**
   Learn how to build `tui-launcher`, initialize your configuration directory, and launch your first interactive view.

2. **[Your First Workflow](first-workflow.md)**
   Learn how to build a self-contained workflow with single-file `.toml` or directory package `workflow.toml`, configure a `picker` engine, and trigger commands upon item selection.
